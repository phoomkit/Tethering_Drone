# Tethering Drone

โครงการพัฒนาโดรนแบบมีสายโยง (Tethered UAV) ที่รับพลังงานไฟฟ้าจากแหล่งจ่ายภาคพื้นดินอย่างต่อเนื่อง โดยมุ่งเน้นความเสถียรในการบิน ระบบส่งกำลังไฟฟ้าที่ปลอดภัย และการสื่อสารกับสถานีภาคพื้นดิน

> **สถานะโครงการ:** อยู่ในช่วงวางแผน ยังไม่มีการสร้างฮาร์ดแวร์ พัฒนาซอฟต์แวร์ หรือบันทึกผลการทดสอบ

## วัตถุประสงค์

1. ออกแบบโดรนแบบมีสายที่รับกำลังไฟฟ้าจากภาคพื้นดินและลอยตัวได้อย่างเสถียร
2. ออกแบบแพลตฟอร์มให้โดรนติดต่อสื่อสารกับสถานีภาคพื้นดินได้
3. พัฒนาระบบสำรองพลังงานบนโดรนเพื่อสนับสนุนความปลอดภัยในการปฏิบัติภารกิจ
4. สร้างแพลตฟอร์มพื้นฐานสำหรับการพัฒนา payload และภารกิจในอนาคต

## ภาพรวมระบบที่เสนอ

| ส่วนประกอบ | หน้าที่ตาม proposal |
| --- | --- |
| Ground Control Station | แหล่งจ่ายไฟ คอมพิวเตอร์สำหรับติดตามและควบคุม และโมดูลสื่อสาร |
| Tether and Power System | ส่งกำลังไฟฟ้าที่แรงดัน 48 V พร้อมวงจรป้องกัน ขั้วต่อ และ strain relief |
| Flight Control System | ประมวลผลการควบคุมการบินและภารกิจ รับข้อมูลจากเซนเซอร์ และสื่อสารกับภาคพื้นดิน |
| Drone Platform | ระบบขับเคลื่อน การจัดการพลังงาน actuators และการจัดเก็บข้อมูล |
| Onboard Battery | เป็นแหล่งพลังงานสำหรับการทดสอบเบื้องต้นและระบบสำรองบนโดรน |

## ขอบเขตโครงการ

- จัดทำ Mass Budget และ Power Budget เพื่อเลือกระบบขับเคลื่อน
- ออกแบบระบบจ่ายพลังงานผ่านสายโยง 48 V วงจรป้องกัน และแผ่นวงจรพิมพ์
- ทดสอบระบบไฟฟ้าและเก็บค่าแรงดัน กระแส และอุณหภูมิ
- ทดสอบการบินด้วยแบตเตอรี่ก่อนติดตั้งสายโยง
- ปรับจูนระบบควบคุมการบินและวิเคราะห์การสั่นสะเทือนเชิงโครงสร้าง
- ทดสอบ tethered hover ในพื้นที่ปิดตามลำดับเวลา 10, 30 และ 60 นาที
- ทำการทดสอบซ้ำด้วยความยาวสายและโหลดที่แตกต่างกันตามทรัพยากร

## แผนการพัฒนา

| Stage | งานหลัก | ผลลัพธ์ที่คาดหวัง | สถานะ |
| --- | --- | --- | --- |
| A - Design & Bench | Mass/Power Budget, เลือก propulsion, ออกแบบ 48 V tether chain, PCB/protection และทดสอบ DC-DC | ค่าพื้นฐาน V/I/temperature และ BOM ที่ยืนยันแล้ว | ยังไม่เริ่ม |
| B - Battery-only Flight | บินโดยใช้แบตเตอรี่เพื่อจูน flight controller และตรวจ structural vibration | ค่าพื้นฐานด้านเสถียรภาพและพฤติกรรมการลงจอด | ยังไม่เริ่ม |
| C - Low-height Tether | Tethered hover ที่ประมาณ 0.5–1 เมตร เป็นเวลา 2–5 นาที | ยืนยันการทำงานร่วมกันก่อนเพิ่มความสูง | ยังไม่เริ่ม |
| D - Formal 3–5 m Test | ทดสอบในพื้นที่ปิดเป็นเวลา 10, 30 และสูงสุด 60 นาที พร้อม logging | Dataset หลักสำหรับ Team Project และ paper | ยังไม่เริ่ม |
| E - Repeatability | ทำซ้ำด้วย tether length/load ที่แตกต่างกัน | ผลเชิงปริมาณและการประเมิน uncertainty/repeatability | ยังไม่เริ่ม |

## ข้อมูลที่ต้องบันทึกในการทดสอบ

- แรงดันและแรงดันตกคร่อม
- กระแสไฟฟ้า
- อุณหภูมิ
- การสั่นสะเทือนเชิงโครงสร้าง
- เสถียรภาพในการบิน
- พฤติกรรมขณะลงจอด
- พารามิเตอร์การบินและระบบไฟฟ้าแบบเรียลไทม์

## ความปลอดภัย

การทำงานกับระบบไฟฟ้า ใบพัด และการทดสอบการบินมีความเสี่ยง ทุกการทดสอบควรดำเนินการในพื้นที่ควบคุมตามกฎของห้องปฏิบัติการ โดยต้องตรวจวงจรป้องกัน current limiting, connector, strain relief, ระบบหยุดฉุกเฉิน และแหล่งพลังงานสำรองก่อนเริ่มทดสอบจริง
