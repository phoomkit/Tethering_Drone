# Final Workflow — Tethered UAV

งานถัดไปคือขึ้นแบบโครง 3D และจำลองการรับแรง โดยแทนอุปกรณ์บนลำที่ยังไม่ได้ออกแบบด้วยมวลก้อนเดียว อ้างอิง [บันทึกการออกแบบและกรณีโหลด](mechanical-design.md) และ [Mass Budget](mass-budget.md)

| ขั้น | เครื่องมือ | งานและผลลัพธ์ |
| --- | --- | --- |
| 1. กำหนดมวลและโหลด | MATLAB, SOLIDWORKS Mass Properties | รวมมวลอุปกรณ์ที่เลือก ประเมินมวลโครงจาก CAD กำหนดมวลสมมติและตำแหน่งบนลำ แยกแรงดึงสายที่จุดยึด |
| 2. ขึ้นแบบโครง 3D | SOLIDWORKS | ขึ้นแผ่นกลาง แขน ฐานมอเตอร์ ขาลงจอด และจุดยึดสาย ตรวจระยะจากศูนย์เพลาจริงถึงใบพัดและชิ้นส่วนรอบข้าง |
| 3. วิเคราะห์โครงสร้าง | SOLIDWORKS Simulation | เปรียบเทียบกรณีลอยตัวและวางบนขาลงจอด ดูความเค้นและการโก่งที่โคนแขน ฐานมอเตอร์ และจุดยึดสาย |
| 4. จำลองการบินและสาย | MATLAB, Simulink, Simscape Multibody | ใช้ Mass Properties จาก CAD สร้างแบบจำลองการเคลื่อนที่และแรงจาก tether |
| 5. ออกแบบและจำลองระบบไฟ | Simscape Electrical, KiCad | ทำ Power Budget จำลองแหล่งจ่าย 48 V สาย และ DC-DC ฝั่งโดรน ออกแบบวงจรป้องกันและ PCB |
| 6. ทดสอบซอฟต์แวร์บิน | PX4 SITL, UAV Toolbox, Simulink | ทดสอบการลอยตัวและการตอบสนองต่อแรงจากสายก่อนใช้ฮาร์ดแวร์จริง |
| 7. ทดสอบบนแท่นและบิน | เครื่องวัดแรงขับ แรงดัน กระแส และอุณหภูมิ, PX4, QGroundControl | ทดสอบระบบไฟและแรงขับบนแท่น → บินด้วยแบต → บินติดสายที่ 0.5–1 ม. → ทดสอบในพื้นที่ปิดที่ 3–5 ม. ตามลำดับ 10 → 30 → 60 นาทีเมื่อผ่านเกณฑ์แต่ละขั้น |
| 8. เทียบผลและจัดทำ Portfolio | MATLAB, SOLIDWORKS, GitHub | เทียบการจำลองกับข้อมูลวัดจริง เก็บแบบ ผลคำนวณ และผลทดสอบให้ตรวจสอบย้อนกลับได้ |
| โบนัส: แบตสำรอง | แบต 4S 2,300 mAh, เครื่องบันทึกแรงดันและกระแส | ทดสอบการสลับจากไฟ tether มาใช้แบตและรักษาระดับเดิม 3 นาที มวลแบตยังอยู่ในงบมวลถ้าติดตั้งบนลำ |
