# ระยะห่างใบพัดของ Quadcopter

แบบ 2D มุมบนใช้วงกลางรัศมี **110 มม.** และแขน 4 เส้นห่างกัน **90°** แต่ละแขนยาว **250 มม. จากขอบวงกลางถึงปลายแขน** สำหรับการตรวจระยะเบื้องต้น ให้ศูนย์กลางวงใบพัดอยู่ที่ปลายแขนตาม [แบบ SOLIDWORKS](../Quadcopter_Layout_2D.SLDPRT)

## วิธีคำนวณ

1. **ระยะจากศูนย์กลางลำถึงปลายแขน**: `R = 110 + 250 = 360 มม.`
2. **ระยะระหว่างศูนย์กลางใบพัดคู่ที่ติดกัน**: เมื่อแขนทำมุม 90° ใช้พีทาโกรัส `d = √(R² + R²) = 360√2 ≈ 509.12 มม.`
3. **แปลงขนาดใบพัดเป็นมิลลิเมตร**: `D = ขนาดใบพัด (นิ้ว) × 25.4` โดยขนาดที่ระบุเป็นเส้นผ่านศูนย์กลาง
4. **หาช่องว่างระหว่างวงใบพัด**: `g = d − (D₁ + D₂)/2` ถ้าใบพัดทั้งคู่ขนาดเท่ากัน ใช้ `g = d − D` ค่าบวกคือวงแยกกัน ค่าศูนย์คือวงสัมผัสกัน และค่าลบคือวงซ้อนกัน

**ตัวอย่างใบพัด 15 นิ้ว**: `D = 15 × 25.4 = 381.0 มม.` จึงเหลือช่องว่าง `g = 509.12 − 381.0 ≈ 128.1 มม.`

ใบพัด 20 นิ้วเหลือช่องว่างตามแบบเพียง **1.1 มม.** ส่วนใบพัด 21 และ 22 นิ้วมีวงซ้อนกัน ก่อนกำหนดขนาดจริง ให้ใช้ตำแหน่ง **ศูนย์กลางเพลามอเตอร์จริง** วัดทั้งสี่คู่ และเผื่อความคลาดเคลื่อนการประกอบ การโก่งของแขนและใบพัด ตลอดจนระยะถึงชิ้นส่วนอื่น

หากกำหนดช่องว่างขั้นต่ำเองเป็น `g_min` และใช้ใบพัดขนาดเท่ากัน ระยะแขนจากขอบวงกลางถึงศูนย์กลางเพลาที่ต้องการคือ `(D + g_min)/√2 − 110 มม.` ภายใต้รูปแบบแขน 90° เดิม
